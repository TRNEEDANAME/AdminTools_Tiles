[h1] Admin Tools Tiles [/h1]

Adds some admin tools that I feel are [i]needed[/i]

[h2] Tools [/h2]

[h3] Tile Copy[/h3]

Basically my [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3808514150]Tile Copy[/url] mod

[list]
[*]Copy a set of tiles
[*]Paste them with a size preview
[*]Share it as a string
[/list]

[h3]Tile Swap[/h3]

Create a set of rules (preset) that allows you to swap tiles around (grass floor -> road), add overlays / tiles (add grass tiles to wood floors) / remove tiles and a lot of such features (with % chance)

[list]
[*]Include a burnt / 10Y later (light), True 10Y later (destroy some wall tiles & more vegetation), Burnt and Bloody tile preset
[*]Share your preset as a string
[*]Undo your changes (up to 20 swaps)
[*]Floor select (can go from -32 to +32 floors)
[*]The tile swap window support tile search (for the swapping & swapped tiles)
[*]Tile Picker for the tile to swap from and to.
[/list]

[h3]Tile Remover[/h3]

A standalone tile remover that works like the tile copy, allows you to remove a set of tiles (kinda superseeded by Tile Swap)

[h3]Tile Builder[/h3]

The Brush Tool window, but drag in the world to build a line / area of the picked tile

[list]
[*]Walls, fences & window walls turn to follow the line
[*]Undo Last takes a drag back
[/list]

[h3]Zone Editor: Building[/h3]

A "Building" mode in the Zone Editor (in the right-click menu in single player)

[list]
[*]Draw a room, pick a floor and / or a wall tile, and build the floor and the walls around it (corner & pillar included) on every floor of the range
[*]Copy House / Paste House
[/list]

[h3]Zone Editor: Swap[/h3]

A "Swap" mode in the Zone Editor (in the right-click menu in single player)

[list]
[*]Tile swap, in a big zone (include a "load" feature that teleports the admin around)
[/list]

[h3]Zone Editor: Loot[/h3]

A "Loot" mode in the Zone Editor (in the right-click menu in single player)

[list]
[*]Loot filler / delete in a big zone
[/list]

[h3]Brush Tool[/h3]

A better brush tool

[list]
[*]Search that stays when the window closes
[*]Search in each category (mods)
[*]Favoutite tiles (stays in a .txt so it's always present)
[*]Bigger tile preview
[/list]

[h3]Loot Filler[/h3]

Select a zone and add loots

[list]
[*]Select floors
[*]Select if the loot comes from your inventory or is rerolled from the vanilla system (container type & location), and if so, is the loot added or deleted -> rerolled
[*]Select the type of fill logic used
[*]Tick categories: filters your inventory list, limits rerolled loot to them, and "Replace" only empties those
[*]Random items by container type: scan the zone's container types, give each one its categories and an amount, and every container of that type gets that many random items
[*]Limit what gets added with an item list: a whitelist (only those items) or a blacklist (never those items). Lists are edited in game, saved, and shared as a string (Export / Import). Built-ins: Military, Gunworks ammo, Survivor
[*]Server-wide blacklist in the sandbox options ("Loot Filler blacklist"), applied on top of any list
[/list]

[h3]Loot Deleter[/h3]

[list]
[*]Select floors
[*]Select the category of loot deleted
[*]Select the % of loot deleted
[/list]
